# Changelog

## 1.0.0

- Syntax highlighting for the OSF language as of OSF 0.6.0: blocks, fields, references,
  `{{ }}` text references, long text with writer's notes, `requires` with `or`
  alternatives, play-history conditions and `next: <node>.options`.
- Comment toggling, bracket matching, auto-closing quotes and braces, and indentation
  for `.osf` files, with two-space indents by default as `osf fmt` writes them.
